ℹ️ Public app connection

Profiles are saved under mrsWolfieTeamMembers in Firebase Realtime Database, separately from Team Wolfpack records. Mrs Wolfie’s public pages can read these profiles. Uploaded images are stored in Firebase Storage under mrs-wolfie/team-members/. After uploading an image, press SAVE MRS WOLFIE PROFILE to publish its new URL.

Firebase Storage rules must separately permit image uploads for the two authorised administrators. A Storage permission-denied error means the Storage rules still need updating; Realtime Database rules alone do not enable uploads.
